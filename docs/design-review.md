# 视觉与交互设计说明

## 设计目标

通勤场景：一只手、屏幕外光线复杂、只想知道「下一班还有多久」。因此界面只强调三件事——**在哪**、**哪条线**、**还有多久**，其余信息降级为辅助。

## 设计令牌

| 项目 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#F4F5F7` 浅灰 | `#0D1014` 近黑蓝灰 |
| 卡片 | `#FFFFFF` + 1dp `#EDEFF3` 描边 | `#161A1F` + 1dp `#262D35` 描边 |
| 主色 | `#1E6FF3` 蓝 | `#7FB2FF` 浅蓝 |
| 强调容器 | `#E8F1FE` | `#14345F` |
| 主要文字 | `#171A1E` | `#E6E9EE` |
| 次要文字 | `#8A9099` | `#9AA3AE` |
| 站间行驶 | `tertiary` 橙红 `#FF5B2B` | `#FF9C7A` |

- 圆角只用三档：卡片 12dp、徽章 8dp、搜索框胶囊；胶囊仅用于 chip、分段控件和主按钮。
- **不用阴影、不用灰色填充堆层次**：卡片靠「纯白 + 1dp 发丝描边」从底色中浮出，深色模式同理。这样在高亮度的户外环境下依然能看清边界。
- 数字统一 `tnum` 等宽数字（站数、分钟、时刻），刷新时不会左右抖动。

## 组件约定

| 组件 | 规则 |
| --- | --- |
| `LineBadge` | 线路号徽章，主色容器底 + 描边；大号用于线路页头部 |
| `ArrivalText` | 右侧到站列，宽度 `76–96dp` 固定，主信息单行省略，副信息仅在有补充含义时出现 |
| `Segments` | 单层描边容器，选中项实心填充，不做「胶囊套胶囊」，也不用勾选图标 |
| `CardSurface` | 全站唯一卡片容器 |
| `Hairline` | 列表行之间 1dp 分隔线，取代卡片内多条独立卡片 |
| `SectionHeader` | 小号字 + 计数并入标题（`线路 · 3`），下方发丝线 |
| `ErrorCard` | 错误描红边、原位重试，不清空已显示内容 |
| `LoadingSkeleton` | 骨架占位，不用整页转圈 |

## 到站信息的去重规则

上游经常同时返回「已到站」和「即将到站」这类同义字段，早期实现会两行都说一遍。现在的规则：

1. 等待发车 → 主信息「计划发车 07:20」，副信息省略。
2. 剩余站数为 0 → 「已到站」。
3. 有剩余站数 → 主信息「N 站」，副信息取时间（如「约3分钟」），两者都无意义时省略。
4. 只有上游文字 → 取状态文字；若状态与时间同义（都含「到站」），只保留一条。

线路页直接以 `arrivalParts` 第一项作为主结论（如「1 站」），时间以辅助文字与结论基线对齐。已到站为绿、即将到站为橙红、在途为蓝、未知为灰。

## 与上一版的差异（本轮重写）

上一版是「Material 3 默认观感」：灰色填充卡片、胶囊套胶囊的分段控件、到站信息重复两行、站台直接暴露上游内部编号（`SM000169`）、状态圆点与大字错位。本轮：

- 重写配色、字阶、形状三套令牌，卡片改为描边式；
- 重写到站信息的取数与排版规则，去掉重复语义；
- 线路页重做头部（大号徽章 + 首末班两栏 + 票价/时刻表入口）与乘车站卡片（时间优先）；
- 时间轴改为连续轨道 + 描边序号点，选中站主色填充，车辆用浅底胶囊挂在站点下方；
- 站台改用「站台 1 / 站台 2」，不再显示内部编号；
- 搜索页、设置页、城市选择统一为同一种卡片 + 发丝线列表语言；
- 深色模式单独校色（卡片描边加深、主色提亮），不是简单反色。

## 复核方式

所有界面都拆成无状态 `XxxContent`，由 Robolectric（`@GraphicsMode(NATIVE)`）渲染成 PNG，存于 `docs/screenshots/`，浅色 / 深色各一张。常规页面为 411×891dp，时刻表另有 360×800dp 窄屏用例，覆盖四列时间网格：

```sh
./build.sh :app:testDebugUnitTest --tests '*ScreenshotTest*'
```

截图只能验证排版、层级和配色，触摸手势、TalkBack、真实字体栅格化仍需真机确认。

## 与厦门公交官方 App 对齐（2026-10-31）

本轮以官方 App 首页为基准重做视觉，参考图存于 `docs/reference/`（应用商店公开截图）。原「青玉绿 + 描边卡片」改为官方蓝色体系：

- 顶栏改为自上而下蓝色渐变，左侧城市下拉、中间标题、右侧刷新，下方一条白色胶囊搜索框；
- 新增四宫格快捷入口（附近站点 / 查公交 / 收藏 / 切换城市）与底部导航（首页 / 搜索 / 收藏 / 设置），选中态仅换色不加胶囊底；
- 站点卡片改为「站名 + 距离 + 箭头」，线路行改为单行「线路号 + 开往终点」，起点降为灰色小字，去掉终点重复表述；
- 到站信息沿用分级配色：已到站主色、有站数主色、等待/未知为次要色；
- 圆角收敛为卡片 12dp / 徽章 8dp / 搜索框胶囊。

核对方式除了 Robolectric 截图，本轮新增 Android 模拟器真机渲染（Android 11 x86_64，软件模拟无 KVM），在模拟器里授予定位、注入厦门坐标后逐页截图比对，确认首页、搜索、线路、时刻表的真实渲染与官方版式一致；深色模式同屏核对。

## 内页版式对齐官方 App（2026-10-31）

本轮沿用 `f6e9c97` 的全线查询和蓝色渐变组件，所有内页使用同一顶栏、12dp 页面外边距、10dp 卡片间距、12dp 描边卡片，无阴影。三个信息层级如下：

| 层级 | 内容 | 字体 |
| --- | --- | --- |
| 主 | 站名、线路号、车牌；实时卡唯一到站结论 | `titleMedium`；结论 `displayMedium` |
| 辅 | 票价、车辆所在站、分钟补充、设置值 | `bodySmall` |
| 元 | 首末班、站序、数量、数据时间 | `labelSmall` |

线路头卡为「起点 → 终点 + 换向图标」「首末班标签 + 时刻表」「票价 + 起点预计发车」。实时卡中选站后呈现乘车站与大字到站；未选站呈现全线车辆数量、首辆车位置与状态，车辆为空时只留标题和灰点。两种状态共用横向站点图。

横向站点图使用 `LazyRow`，左右内容留白 8dp，每列宽 64dp、至少高 152dp；车辆区 26dp、序号 `labelSmall`、轨道区 22dp、横轨 3dp、站点 12dp。站名竖排，12sp 字号 / 14sp 行高，最多六行并省略。原 132dp 无法完整容纳六行站名，故改为最小 152dp，允许字体缩放时自然增高。选中站为实心蓝点加白心、蓝字；车辆用 18dp 小巴，站间车辆透明度 38%，多车叠数量。初始滚到乘车站，否则首辆车所在站。

时间轴外层为一个点击节点，轨道用 `matchParentSize` 跟随自然行高，最小 56dp；不再混用固有尺寸测量。序号与轨道清空辅助语义，整行合并站名、选中状态与车辆数。分段控件视觉高 36dp、触控区高 48dp，浅蓝选中底。深色分支统一使用 `isSystemInDarkTheme()`，截图也同步系统模式。

搜索使用白色胶囊输入框和历史关键词流，结果标题直接贴卡；站点使用站名头卡、横向站台分段以及行内两条到站；时刻表为无描边 40dp 时间格和当前时段竖条；城市定位行用主色容器底；设置行高 56dp，关于说明单独成卡。

去掉解释性文案，是为了让选中颜色、车辆小巴、数字层级和操作位置表达状态。业务界面不再教学或重复数据免责声明；到站更新、覆盖和定位说明统一收进「设置 → 关于」。时刻表上游必要说明保留为最小元文字。所有固定可见文案来自 `strings.xml`，清理前后均检查资源引用；无障碍标签可保留完整含义。

本轮不启动模拟器。38 张真实 Compose PNG、整行点击语义、未选站提示消失等断言由截图测试核对，验证结果与环境限制见 [内页验收记录](inner-pages-validation.md)。
